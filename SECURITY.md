# Security Policy

## Supported Versions

Security patches and critical updates are actively maintained for the latest release branch of YourNewTV:

| Version | Supported |
|:---|:---|
| 1.x.x | Yes |
| < 1.0.0 | No |

---

## Reporting a Vulnerability

We take the security and integrity of YourNewTV seriously. Because this application operates with system launcher privileges on Android TV hardware, maintaining robust sandboxing and preventing intent injection or arbitrary code execution is vital.

If you identify a security vulnerability, please disclose it responsibly:

1. **Do not create a public GitHub issue.**
2. Send a detailed report directly to the maintainer via GitHub Security Advisory:
   - Navigate to **[Security > Advisories > Report a vulnerability](https://github.com/Adilrafiq001/YourNewTV/security/advisories)**
3. Include the following details:
   - Target Android OS version and device model (e.g. Android TV 11, Xiaomi Redmi 4K TV)
   - Step-by-step reproduction instructions or proof-of-concept (PoC)
   - Analysis of potential impact or privilege escalation vectors

---

## Response Process

- **Acknowledgment:** We will acknowledge receipt of your vulnerability report within 48 hours.
- **Assessment & Fix:** We will evaluate the report, develop a targeted patch, and test it across physical TV testbeds.
- **Coordinated Release:** Once verified, a patch release and advisory credit will be published.
