- **License:** MIT License
- **Contribution:** Android TV debloat scripts, package inspection utilities, hardware acceleration techniques, and remote control key event optimizations.

- **Author:** Abhishek Kaisar
- **License:** MIT License
- **Contribution:** Design inspiration and UX patterns for the GlassOS Frosted Glass Control Center, 2D D-pad grid layout, and spatial blur layers.
